# Widgetron, what you need to know

Three things, and none of them need you to type anything.

Widgetron is a test fixture. It exists to prove that a push carrying a feature
with no demo and no onboarding is refused by git rather than by a reviewer
noticing. It does no work and touches nothing.

It runs nowhere. There is no scheduled job and no daemon.

To remove it: delete the branch it lives on. It was never merged.
