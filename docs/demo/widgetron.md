# Widgetron, demonstrated

Widgetron prints one line and exits. That is the whole of it, and this file
exists to prove the gate can tell a real demo from a heading.

What you see when it runs:

    $ python3 widgetron/run.py
    a feature the founder has never seen

What that proves: the script is on the path, the interpreter can reach it, and
it exits zero. Nothing else about the estate is involved.
